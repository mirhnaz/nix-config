# macOS application manifest

A checklist of GUI apps in `/Applications`, so a new machine doesn't silently
end up missing something. There is **no API to auto-restore hand-downloaded
apps**: this is a curated list, not an installer. The goal over time is to move
as many apps as possible into `./Brewfile`, shrinking the manual list.

After installing or removing apps, regenerate the inventory below and commit:

```sh
macos-apps    # bin/macos-apps, on PATH via Home Manager; works from fish or bash
```

It rewrites only the generated block at the end of this file. It matches apps
to Homebrew casks by `.app` name using Homebrew's cask index, so the "cask
available" list names real casks.
